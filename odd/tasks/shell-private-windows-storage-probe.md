## Key Learnings

- `x/sys/windows v0.47.0` exposes `GetVolumeInformationByHandle` and `FILE_PERSISTENT_ACLS`, but not the required `NtQueryVolumeInformationFile`/`FileFsDeviceInformation` binding and remote constants; test-local binding is an experiment, not a production dependency decision.
- The parent 1a held direct root is *untrusted*. Same-handle FS/device observations and two equal DOS mappings cannot alone prove which root the mapping names or prove physical locality.
- **BLOCK:** documented safe user-mode query semantics and an exact public mapping-to-held-root identity proof are missing. Preserve `ErrUnsupported` until those contracts and later parent units are independently resolved.
