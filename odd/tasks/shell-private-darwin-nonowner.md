## Test design (future B implementation, not present)

1. `newOwnerACLFixture(t)` creates a unique disposable `/private/tmp` parent and held empty `0600` child. `proveOwnerACLReplacement(t, file, path, before)` must pass **before** any child payload. A's inode check requires size zero, so never call it on the child after writing. Do not use a real private destination. Write a fixed benign synthetic marker only to that held child, verify full write, sync/close as appropriate, and check owner can reopen/read the exact marker. Keep cleanup of the disposable parent even on failure.
2. Before lowering parent mode to `0711`, create a separate benign canary/control file under the same parent, with owner/readable permissions verified, then chmod parent `0711` and verify mode. The parent ACL may still have its inherited `everyone` setup; this is an experiment in **child** denial, not parent confidentiality. The probe must open the canary through the same parent path and demonstrate ancestor traversal and readable control data; it must also successfully stat the child pathname as a precondition to the read attempt. If traversal, canary read or child pathname stat fails, child denial is inconclusive and the test **fails**.
3. Require passwordless `sudo -n -u _nobody` on native macOS (no prompts). Verify probe's actual effective UID via the same execution path, distinct from child owner and nonzero; do not infer identity from the username. Use direct `exec.Command` arguments, never interpolate an untrusted pathname into shell code; if a fixed helper is required, pass paths as separate arguments. The nonowner process must really open the child pathname for `O_RDONLY` (and `O_WRONLY` if included), returning a classified `EACCES`/`EPERM` denial, not just a missing file or nonzero exit. Assert attempted read produces **empty file-data stdout**; do not print the marker or count test-harness diagnostics as file data. Any successful child open, different errno, probe failure, unavailable sudo, same/root UID, or missing canary proof is FAIL/BLOCK, never SKIP or fallback owner-only success. No `testing.Short()` escape for this required native proof.
4. Capture exact native fork `workflow_dispatch` SHA/run URL, selector listing, A and B focused outputs, exit codes, and independent review disposition. A's green is a prerequisite, not B's result. - A denial without actual distinct UID and a readable same-parent control is inconclusive; missing sudo must fail closed.
